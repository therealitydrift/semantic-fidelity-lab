## Folder Purpose

This folder is intended as a clean Markdown archive of Semantic Fidelity Project essays originally published on Substack. The collection tracks the development of semantic fidelity as a vocabulary for understanding AI systems that remain fluent, coherent, and operational while meaning, context, grounding, and constraint gradually weaken.

## Core Themes

The essays in this folder focus on several related patterns:

- Semantic fidelity as meaning preservation across transformation
- Semantic drift as gradual mutation of meaning
- Fidelity decay as accumulated loss through compression and reuse
- Compression as both a useful process and a source of hidden semantic loss
- Ground erosion, lexical decay, semantic noise, and meaning debt
- Constraint collapse and survivable wrongness in symbolic systems
- The limits of accuracy, faithfulness, and hallucination-based evaluation
