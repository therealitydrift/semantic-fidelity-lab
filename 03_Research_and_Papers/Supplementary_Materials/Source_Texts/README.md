# Source Texts

## Supporting Reference Materials

### Overview

This directory contains source texts and early reference materials used in the development of the Semantic Fidelity Lab.

These documents provide background context for the lab’s work on semantic fidelity, meaning erosion, drift, and fidelity-aware evaluation in AI systems.

---

## Contents

This directory includes source materials related to:

- Drift and meaning loss in AI systems
- Semantic erosion and fidelity decay
- Fidelity-aware evaluation
- Early benchmarking concepts

---

## Role Within the Semantic Fidelity Lab

Source texts provide supporting context for the broader Semantic Fidelity framework.

They are useful for orientation and development history, but they should not be treated as the current canonical framework unless explicitly marked as such.
