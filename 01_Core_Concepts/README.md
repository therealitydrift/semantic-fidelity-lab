# Core Concepts

This directory contains the primary concept papers for the Semantic Fidelity framework.

Each paper develops a core concept describing how meaning changes as language moves through systems, representations, compression, and artificial intelligence. Together, these concepts form the conceptual foundation of the Semantic Fidelity framework.

---

## Included Concepts

### Constraint Collapse

Examines what happens when feedback and constraints remain present but no longer meaningfully preserve the relationship between language and reality.

### Semantic Fidelity

Defines the central concept describing whether meaning, intent, and reference survive as information moves through language, models, and AI systems.

### Drift Principle

Describes the broader tendency for representations to gradually lose alignment with their original meaning as they undergo repeated transformation.

### Semantic Drift

Examines how meaning gradually changes as language circulates through people, institutions, platforms, and AI systems.

### Recursive Compression

Explores how repeated summarization, abstraction, and regeneration progressively reshape information until representations begin functioning as sources for one another.

---

## Reading Order

Readers new to the framework should begin with **Semantic Fidelity**, followed by **Constraint Collapse**, **Semantic Drift**, **Recursive Compression**, and **Drift Principle**.

Together these papers establish the conceptual foundation for the broader Semantic Fidelity framework.
