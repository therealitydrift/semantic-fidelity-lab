# Visual Guides

This directory contains visual reference materials for the Semantic Fidelity framework.

These documents use diagrams, comparisons, and simplified visual models to explain key concepts related to meaning preservation, semantic degradation, and AI-mediated communication. They are intended as companion resources to the framework's concept papers and research publications.

---

## Directory Structure

### 01_Visual_Reference_Guides

Concise visual explainers comparing related concepts, illustrating core mechanisms, and providing accessible introductions to the Semantic Fidelity framework.

### 02_Visual_Diagrams

Conceptual diagrams, system models, and structural illustrations showing how meaning changes across language, compression, representation, and AI systems.

---

## Purpose

These visual materials provide quick reference resources for readers seeking an accessible introduction to the Semantic Fidelity framework. They complement the written papers by presenting key ideas in diagrammatic and visual form.
